02 / SELECTED WORK

公開作品

Codex Desktop · 實驗性工作流程 · MIT

Desktop Thread Worker

一套輕量的 Planner／Worker skill。使用者決定範圍，Planner 整理任務與驗收，固定的 Worker 持續實作並回傳證據。

設計重點是明確交接、延續上下文，以及達成約定條件後停止。它是指令式工作流程，並非具備強制執行保證的排程系統。

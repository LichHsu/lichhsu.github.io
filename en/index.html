01 / ABOUT

About me

I care about software that remains maintainable: clear module responsibilities, bounded changes, and verification results that support delivery decisions.

My public notes start with AI-assisted development. I explore how to assign planning, implementation, and review responsibilities, preserve working context, and keep people in control of direction.

The views here are my own. Notes based on work experience describe general methods and exclude company, client, and internal system details.

02 / SELECTED WORK

Codex Desktop · Experimental workflow · MIT

Desktop Thread Worker

A lightweight Planner / Worker skill. The user sets the scope. The Planner prepares tasks and reviews results. A persistent Worker implements changes and returns evidence.

The design focuses on clear handoffs, context continuity, and stopping when the agreed conditions pass. It is an instruction-based workflow, not a scheduler with enforced execution guarantees.
